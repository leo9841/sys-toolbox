# 🛠️ Linux Tidy & System Toolbox

A lightweight utility script designed to clean, monitor, and optimize Linux systems without bloat.

## ✨ Features
- **Smart Cache Cleaner:** Clears out old caches and temporary files safely.
- **Broken Symlink Finder:** Finds dead or broken links.
- **Resource Health Check:** Quick overview of RAM and disk stats.
